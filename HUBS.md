# Hub pages: /reels, /posts, /notes

Static pages (no JavaScript) built by `build_hubs.py` from JSON files in `data/`.
Live at https://substacktoday.github.io/reels/ , /posts/ , /notes/. The home page links to all three at the top.
`build_hubs.py` never edits `index.html`; the home grid is still owned by `grid.py`, `log_post.py` and `update.py`.

## Rebuild

    python3 build_hubs.py                  # rebuild pages from data/*.json
    python3 build_hubs.py --refresh-posts  # also re-fetch the Substack archive into data/posts-hub.json

`log_post.py` (run after every Instagram post) already marks a posted reel live, refreshes posts, rebuilds the hubs and pushes.

## Add a reel (`data/reels.json`)

Entries render in file order (put the newest posted reels first). Fields:

    {"id": "short-slug",                      // also the thumbnail name
     "title": "Reel title",
     "writer": "Writer name",                 // credit shown on the card
     "publication": "Publication name",
     "status": "posted" | "scheduled",        // scheduled shows a "Coming soon" badge and no Watch button
     "ig": "https://www.instagram.com/substacktoday/reel/XXXX/",   // "" until posted
     "articles": [{"label": "Read the article", "url": "https://...specific article..."}],
     "cover": "img/reels/short-slug.jpg"}

- `articles` must be the SPECIFIC article URL, never a profile or home page. Roundup reels list several articles, one button each.
- Make the thumbnail: `python3 build_hubs.py --thumb <1080x1920-cover.png> <id>` (writes `img/reels/<id>.jpg`, 360x640).
- When a reel is posted: set `"status": "posted"` and fill `"ig"`. When a reel is deleted and reposted, replace the `ig` URL and re-run `--thumb` if the cover changed.
- Add `"hidden": true` to keep an entry in the file but off the page.

## Add a Note (`data/notes.json`)

    {"url": "https://substack.com/@materialgirlimmaterialworld/note/c-NNNN",
     "date": "2026-10-15",
     "kind": "note" | "restack",
     "about": "Restack: Publication, \"Title\"",   // optional line under the date (used for restacks)
     "text": "The note text",
     "read_url": "https://brookekaylee.substack.com/p/slug"}   // optional second link

Notes are shown newest first (by date, then by id). `"hidden": true` hides one.

## Posts (`data/posts-hub.json`)

Generated by `--refresh-posts` from https://brookekaylee.substack.com/api/v1/archive (public posts only; hook = the post subtitle). Don't edit by hand.

## Notes on automation

- The daily GitHub Actions workflow (`update.yml`) only stages `index.html posts.json img`, so it does not touch the hub files. Hub pages update whenever `log_post.py` or `build_hubs.py` runs on the box and is pushed.
- Do not put a hub link inside `<nav class="g">`; `grid.py` rewrites that block.
